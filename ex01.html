Selecionando os elementos DOM

Posso selecionar os elementos DOM: por marca (tagname); por ID; por classe; por seletor (por CSS).

Existem alguns comandos que nós vamos utilizar

Por marca (tagname)

O comando é o getElementsByTagName

Como está no plural: getElements... eu preciso dizer o número do elemento que eu quero utilizar, lembrando que no JS, a contagem dos elementos começa do zero.

Por Id

O comando é: getElementByID

Preciso atribuir um ID na tag que eu quero manipular.

Por ClassName

O comando é o: getElementsByClassName

Por seletor de CSS

O comando é querySelector

Se a tag que eu quero selecionar estiver com um id, eu usso hashtag(#), mas, se estiver com uma class, eu uso ponto.

Selecionando por name

O comando é getElementsByName
